การจัดการข้อมูลห้องน้ำ (ตาราง toilets และ toilet_amenities)

ใช้สำหรับเพิ่มจุดห้องน้ำใหม่ เปลี่ยนสถานะ (ปกติ/ทำความสะอาด/ชำรุด) และติ๊กเลือกสิ่งอำนวยความสะดวกที่มีในห้องน้ำนั้นๆ

การจัดการข้อมูลอาคาร (ตาราง buildings)

รายชื่อตึกและคณะต่างๆ ใน มธ. ท่าพระจันทร์ เมื่อเพิ่มตึกที่นี่แล้ว จะสามารถนำไปเลือกตอนสร้างห้องน้ำหรือจุดอ้างอิงได้

รหัสอาคาร (ID) ชื่ออาคาร / คณะ รายละเอียดเพิ่มเติม / จุดสังเกตตึก จำนวนห้องน้ำในตึกนี้ ปุ่มจัดการ
การจัดการจุดอ้างอิง/ห้องสำคัญในอาคาร (ตาราง locations)

ใช้ระบุห้องเรียน ห้องสมุด หรือจุดสำคัญในแต่ละชั้น เพื่อช่วยให้ผู้ใช้งานเทียบตำแหน่งเดินไปห้องน้ำได้ง่ายขึ้น

รหัส (ID) อาคาร ชั้น ชื่อห้อง / จุดอ้างอิง คำอธิบายเส้นทาง ปุ่มจัดการ
การจัดการสิ่งอำนวยความสะดวก (ตาราง amenities)

จัดการตัวเลือกสิ่งอำนวยความสะดวก เช่น สายฉีดชำระ ห้องน้ำผู้พิการ กระดาษทิชชู่ เพื่อให้ผู้ใช้กดกรองค้นหาในแอปได้

รหัส (ID) ชื่อสิ่งอำนวยความสะดวก ปุ่มจัดการ
รายการแจ้งปัญหาห้องน้ำชำรุด / อัปโหลดรูปภาพ (ตาราง reports)

ตรวจสอบรายการที่ผู้ใช้แจ้งเข้ามาพร้อมรูปถ่าย หรือกดปุ่มด้านขวาเพื่อบันทึกแจ้งปัญหาใหม่พร้อมแนบรูปภาพประกอบ

รหัส วัน-เวลาที่แจ้ง ห้องน้ำที่เกิดปัญหา ประเภทปัญหา รายละเอียด รูปถ่ายประกอบ ปุ่มจัดการ
ความคิดเห็นและคะแนนความสะอาด (ตาราง reviews)

รวบรวมคะแนนรีวิว (1-5 ดาว) จากนักศึกษาและบุคลากรหลังเข้าใช้งานจริง

รหัสรีวิว วันที่รีวิว สถานที่ห้องน้ำ ผู้รีวิว คะแนนความสะอาด ความคิดเห็น ปุ่มจัดการ
รายชื่อผู้ใช้งานและผู้ดูแลระบบ (ตาราง Users และ admin)

จัดการข้อมูลผู้ใช้งานในระบบและกำหนดสิทธิ์ผู้ดูแลระบบ

รหัสผู้ใช้ (User ID) ชื่อที่แสดง (Display Name) กลุ่มผู้ใช้ (Role) เบอร์โทรศัพท์ สิทธิ์ผู้ดูแล (Admin) ปุ่มจัดการ
ตั้งค่าการเชื่อมต่อฐานข้อมูล Supabase จริง

นำ Project URL และ Publishable Key จากหน้าเว็บ Supabase ของคุณมาวางด้านล่าง เพื่อให้เว็บนี้ดึงและบันทึกข้อมูลลงตารางจริงทันที
